# 🛒 ClickNBuy – Full Stack eCommerce Web Application

ClickNBuy is a modern full-stack eCommerce web application built using Spring Boot, Thymeleaf, Hibernate, and H2 Database. The platform delivers a seamless online shopping experience with secure authentication, product management, shopping cart functionality, order processing, and responsive UI design.

Designed with clean MVC architecture and real-world workflow implementation, the project demonstrates scalable backend development practices using the Java Spring ecosystem.

---

## ✨ Features

- 🔐 Secure User Authentication & Authorization
- 🛍 Product Browsing and Management
- 🛒 Shopping Cart Functionality
- 📦 Order Placement & Order Processing
- 📧 Email Integration using Spring Mail
- ☁️ Cloudinary Image Upload Support
- 📱 Twilio Notification Integration
- 🎨 Responsive Thymeleaf UI
- 🗂 Hibernate / JPA ORM Integration
- ⚡ Scalable Spring Boot Backend Architecture
